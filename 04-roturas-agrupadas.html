FUNDAMENTACIÓN / 04 DE 06

Una DSB exige dos hebras afectadas.

Un daño localizado no equivale automáticamente a una mutación. Primero hay que definir qué evento cuenta como lesión. En este modelo, una rotura doble (DSB) se registra cuando existe al menos un sitio roto en cada hebra con separación longitudinal no mayor de diez pares de bases. Al repetir el experimento virtual se estima una frecuencia condicional por desintegración simulada.

ECUACIÓN DE REFERENCIA
DSB ⇔ ∃ i,j : Aᵢ = 1 ∧ Bⱼ = 1 ∧ |i−j| ≤ 10 ; SE = √[p(1−p)/n]

Fundamento: Modelo Python original · criterio operativo 10 pb.

Cómo construimos este modelo

  1. En cada desintegración virtual se sortea, independientemente en cada sitio, si ocurre una rotura según pⱼ.
  2. Se recorren las dos hebras buscando un par de roturas con separación de como máximo diez bases; ese umbral es una convención operativa.
  3. Se repite el experimento 3.500 veces, con semilla reproducible, y se muestra p̂ junto con su error estándar binomial. No es una medida observada.

Las DSB reales involucran química de radicales, estructura cromatínica, correlaciones entre depósitos de energía y mecanismos que este muestreo Bernoulli no contiene. No hay que interpretar p̂ como rendimiento real de DSB del ¹²⁵I.
